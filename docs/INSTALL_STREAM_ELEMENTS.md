# Установка в StreamElements

Основная инструкция: **[Превью → StreamElements → OBS](QUICKSTART.md)**.

Она описывает загрузку своих персонажей, копирование четырёх вкладок, выбор файлов в медиатеке, команды, масштаб и обновление существующего виджета. В архиве релиза эта же инструкция находится в `INSTALL.md`.

- [Все настройки](CONFIGURATION.md)
- [Подготовка медиа и шрифтов](ASSET_GUIDE.md)
- [Переход со старой версии и ошибка 413](TROUBLESHOOTING.md)

При обновлении используй сохранённый JSON проекта, полностью заменяй HTML/CSS/JS/FIELDS и не очищай DATA. Анимации для эфира выбираются в медиатеке: локальный JSON проекта не загружает их туда автоматически.
