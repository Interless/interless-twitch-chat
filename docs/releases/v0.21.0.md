# Interless Chat 0.21.0

От первоначального минимального оверлея проект вырос в настраиваемый палеонтологический Twitch-чат с локальным редактором. Релиз объединяет накопленные изменения после 0.1.0.

## Главное

- Костяные рамки, плашки имени и стилизованные значки ролей.
- Строгое чередование плашки слева/справа от персонажа внутри компактного стека.
- Полное превью со своим текстом, ником, ролью и случайным назначением персонажей.
- RGB/HEX-палитра элементов, независимая прозрачность поверхностей и 10 шрифтов с кириллицей.
- 11 фоновых рисунков со случайными координатами и углами, ограничением плотности и плавной сменой.
- Спокойное движение сообщений с режимом, частотой и размахом.
- Свои персонажи из папки/файлов, персональный выбор командой и JSON проекта с исходниками.
- Изменение команды в превью или непосредственно в StreamElements, включая кириллицу; старое название не остаётся алиасом.
- Общий масштаб 25–200% в превью и StreamElements, отдельный размер динозавров.
- Прямое копирование HTML/CSS/JS/FIELDS с текущими настройками.

## Изменение установки

**Персонажи теперь хранятся в медиатеке StreamElements.** В копируемом JavaScript нет Base64 анимаций. CSS содержит только выбранный WOFF2. Это убирает основной источник больших запросов сохранения Overlay, которые приводили к 413.

Стандартных динозавров в релизе нет. Выбери свои файлы в превью, скопируй четыре вкладки, затем загрузи/выбери эти же файлы в «Динозаврики — медиатека». FIELDS создаёт поля файлов, команд и общего масштаба. Остальное оформление задаётся в локальном редакторе.

## Обновление

1. Распакуй архив релиза и открой `preview.html`.
2. Открой свой сохранённый проект JSON либо выбери файлы и настрой оформление заново.
3. Полностью замени четыре вкладки существующего Custom Widget; **DATA не очищай**.
4. Проверь медиа, команды и масштаб, затем сохрани Overlay. URL для OBS остаётся прежним.

Для списка команд, отправляемого ботом, настрой Custom commands отдельно. Изменения, сделанные только в StreamElements, не синхронизируются обратно в локальный проект. Дополнительных пустых слотов персонажей в 0.21.0 ещё нет.

## В архиве

`preview.html`, HTML/CSS/JS и базовые FIELDS, `INSTALL.md`, `FONT-LICENSE.txt`, `BOT-SETUP.txt`, `DINOSAURS.json`. Для своего оформления используй кнопки копирования из превью. Рядом с ZIP публикуется SHA-256.

Проверки: `npm run check` — форматирование, lint, TypeScript, 85 unit/component-тестов, сборка и DOM-проверки готового превью/копируемого кода. Работа конкретных видео и прозрачности в целевом OBS проверяется отдельно.
