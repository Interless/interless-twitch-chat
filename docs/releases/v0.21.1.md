# Interless Chat 0.21.1

В релизе публикуется один установочный ZIP, без отдельного файла `.zip.sha256`.

Исправлен разбор повторяющихся Twitch-смайликов: последний смайлик не отбрасывается при конечной позиции, совпадающей с длиной сообщения. Поддерживаются включительные и исключительные границы, Unicode/UTF-16 позиции и повторения из raw emotes tag. Пробелы, обычный текст и пунктуация сохраняются.

Проверки покрывают 1/4/30/80 повторений, emoji и русский текст перед смайликами, дубликаты и недопустимые позиции. Отдельный сценарий готового превью отправляет 40 повторений через событие StreamElements и проверяет их отображение картинками.

## Обновление

1. Открой сохранённый JSON проекта в новом `preview.html`.
2. Скопируй HTML/CSS/JS/FIELDS в существующий Custom Widget и сохрани Overlay. DATA не очищай.
3. Проверь повторяющиеся смайлики в обычном сообщении и в конце строки.

Файлы персонажей остаются в медиатеке. Повторная загрузка анимаций не требуется; проверь выбранные медиа, команды и масштаб после обновления.
