# Настройки Interless Chat

Полный редактор находится в `preview.html` внутри архива релиза. Это локальная страница: свои тестовые сообщения не отправляются в Twitch.

## Что переносится в эфир

| Данные                                                                  | Как сохраняются и применяются                                             |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Цвета, прозрачность, шрифт, размеры, движение, декор                    | Настраиваются в превью и фиксируются в копируемом коде                    |
| Общий масштаб                                                           | Начальное значение из превью; затем можно менять ползунком StreamElements |
| Команды персонажей                                                      | Начальные значения из превью; затем можно менять в StreamElements         |
| Изображения и видео                                                     | Локальные исходники для превью; отдельный выбор в медиатеке для эфира     |
| Закрепление тестовых сообщений, тестовые ники/роли, фон страницы превью | Используются только для проверки, в эфир не переносятся                   |

Если меняешь оформление, скопируй четыре вкладки заново. Для изменения масштаба, команды или выбранного файла непосредственно в StreamElements достаточно сохранить Overlay. Значения этих полей не синхронизируются обратно в превью.

## Размеры и расположение

| Регулятор                       | На что влияет                                                                       |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| Общий масштаб, 25–200%          | Вместе меняет рамку, текст, значки, динозавра и промежутки. 100% — исходный размер  |
| Размер динозавриков             | Пропорция персонажа относительно плашки до общего масштабирования                   |
| Минимальная/максимальная ширина | Размер плашки, включая переносы длинного текста; учитывается доступная ширина сцены |
| Расстояние между сообщениями    | Вертикальный промежуток, который также учитывает запас для покачивания              |
| Отступ по горизонтали / снизу   | Положение блока относительно сцены; общий масштаб сохраняет эти отступы             |
| Привязка блока                  | Слева, по центру или справа                                                         |
| Сторона персонажа               | Чередование относительно плашки либо постоянная сторона                             |
| Время сообщения в эфире         | Через сколько сообщение начинает исчезать                                           |
| Максимум сообщений              | Ограничение числа одновременно показанных сообщений                                 |

Режим «Держать сообщения в превью дольше» продлевает их жизнь до 120 секунд только в редакторе. Скопированный код использует выбранное время эфира.

## Цвета и прозрачность

В палитре выбери элемент, затем цвет через RGB, HEX или системное окно выбора. Доступны текст, ник, плашки, рамка/кости, акценты, декор, разделитель, тень, символ/фон/контур значка. Можно вернуть исходный цвет одного элемента или сбросить всю палитру.

Отдельные ползунки управляют непрозрачностью тела сообщения и плашки имени. Видимость фоновых значков ограничена диапазоном 0–70%. Общая цветовая схема может сохранять различия по ролям или делать все плашки светлыми/тёмными.

## Шрифты

| Стиль       | Шрифты                                   |
| ----------- | ---------------------------------------- |
| Пиксельные  | Press Start 2P, Tiny5                    |
| Обычные     | PT Sans, Rubik, Comfortaa                |
| С засечками | Lora                                     |
| Рукописные  | Marck Script, Bad Script, Caveat, Neucha |

Выбор и размер видны на примере строки и показанных сообщениях. В копируемом CSS остаётся один выбранный шрифт WOFF2. Остальные доступны в превью. Исходные TTF и лицензии лежат в репозитории; глифы при подготовке WOFF2 не перерисовываются.

## Движение плашек

Можно выбрать плавное покачивание вверх-вниз, пиксельные шаги или хаотичные пиксельные сдвиги. Частота регулирует скорость движения, размах — расстояние смещения. Нулевая частота или нулевой размах выключают покачивание. Движение разных сообщений не синхронизировано; вход и выход настраиваются отдельно.

## Фоновые значки

11 переключателей: косточка, книга, аммонит, геологический молоток, след динозавра, череп, трилобит, папоротник, кисточка, колба и бутылка пива.

| Регулятор                   | Поведение                                                                          |
| --------------------------- | ---------------------------------------------------------------------------------- |
| Общий переключатель         | Выключает весь декор                                                               |
| Плотность, 0–100%           | Заполняет доступную площадь; короткая плашка всё равно ограничивает число рисунков |
| Сообщений с декором, 0–100% | Доля сообщений, которые получат рисунки                                            |
| Частота смены, 0–100%       | 0 — статичный набор; остальной диапазон — примерно от 30 до 3 секунд между сменами |
| Видимость, 0–70%            | Прозрачность фоновых рисунков                                                      |

Координаты и углы случайные. Учитываются габариты повёрнутых рисунков, отступы друг от друга и краёв. Если места нет, новые элементы пропускаются. При смене набор затухает, затем появляется следующий; рисунки не меняют высоту плашки.

## Динозавры и команды

Выбери папку или файлы. Имя файла создаёт начальную команду; кириллица в имени транслитерируется для внутреннего ID. В карточке персонажа можно указать другую команду и нажать «Изменить команду». Название допускает 1–32 буквы/цифры, `_` и `-`, первая — буква; латиница и кириллица поддерживаются. В поле настроек `!` необязателен, в Twitch команда отправляется с `!`.

Команды уникальны, регистр не важен. `!dino`, `!ichat` и `!interless_chat` заняты справкой. Переименование не сохраняет старое название как алиас. В превью недопустимое название отклоняется с ошибкой под полем. В StreamElements недопустимые/повторяющиеся названия возвращают соответствующие команды к значениям из превью.

Кнопка «Назначить случайных динозавриков» меняет персонажей уже показанных авторов. У одного автора сохраняется один персонаж. В настоящем чате команда влияет только на его последующие сообщения; старые карточки не переписываются.

## Сохранение и обновление

- **Сохранить проект:** JSON с параметрами и локальными файлами для дальнейшего редактирования.
- **Открыть проект:** восстановление этого JSON в превью, включая переименованные команды.
- **JSON пресета:** только параметры, без набора анимаций. Находится в дополнительных настройках.
- **Четыре кнопки копирования:** текущий вариант для вкладок HTML/CSS/JS/FIELDS в StreamElements.

Папка читается при выборе и не отслеживается в фоне. После изменения файлов выбери её повторно. Новый набор заменяет предыдущий; команды для сохранившихся внутренних ID сохраняются. При обновлении Custom Widget не очищай DATA и проверь файлы, команды и масштаб после вставки кода.
