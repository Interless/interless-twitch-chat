# Ручная проверка релиза

Автоматические проверки запускаются через `npm run check`. Этот список используется для целевого браузера, реального StreamElements и OBS; отметки не означают, что все сценарии уже выполнены.

## Установка и перенос

- [ ] ZIP и SHA-256 соответствуют релизу; `preview.html` открывается локально.
- [ ] Старый JSON проекта открывается с настройками и своими анимациями.
- [ ] HTML/CSS/JS/FIELDS копируются в новый Custom Widget.
- [ ] При запрещённом буфере можно скопировать выделенный код через Ctrl+C.
- [ ] В нативных настройках есть масштаб, команды и выбор медиа.
- [ ] Те же файлы выбраны из медиатеки, Overlay сохраняется без 413.
- [ ] При обновлении того же виджета DATA не очищается; медиа, команды и масштаб проверены.
- [ ] Выбранный шрифт соответствует превью; остальные девять не добавлены в копируемый CSS.

## Превью

- [ ] Работают свой текст, ник и роль, Enter/Shift+Enter.
- [ ] Режим длительного просмотра не меняет экспортированное время эфира.
- [ ] Тестовые сообщения и фон страницы не попадают в эфир.
- [ ] Сохранённый проект восстанавливает оформление, команды и исходники.
- [ ] Компактный пресет меняет настройки, не подменяя его JSON проектом с медиа.

## Карточки, роли и масштаб

- [ ] Плашки относительно персонажа идут слева/справа/слева/справа для сообщений разной длины и ролей.
- [ ] Команды не переключают очередь сторон; удаление не переставляет стороны оставшихся карточек.
- [ ] Привязка блока слева/по центру/справа и отступы работают.
- [ ] Масштаб 25/100/200% меняет рамку, текст, значки и персонажа вместе.
- [ ] Нативный масштаб StreamElements меняет размер без повторного копирования кода.
- [ ] Текст переносится на узкой и широкой сцене; высокий стек обрезается сверху.
- [ ] Корона/молоток/меч/алмаз/таракан соответствуют входящим ролям; дополнительные значки подписки не теряются.
- [ ] RGB-палитра, схемы и независимая прозрачность поверхностей соответствуют превью.

## Персонажи

- [ ] Пустой набор не оставляет сломанной картинки или пустого места.
- [ ] Импорт заменяет предыдущий набор; первый персонаж используется по умолчанию.
- [ ] Команда выбирает персонажа только для следующих сообщений автора.
- [ ] В превью ручной/случайный выбор обновляет уже показанные сообщения согласованно для одного автора.
- [ ] Переименование в превью и StreamElements сохраняет файл и назначения; старое название не работает как алиас.
- [ ] Недопустимые, зарезервированные и повторяющиеся команды обрабатываются без поломки чата.
- [ ] WebM/MP4 воспроизводится muted/loop/autoplay в целевом OBS; прозрачность проверена.
- [ ] Файлы с URL без расширения выбирают правильный image/video элемент.
- [ ] Список команд бота настроен отдельно и соответствует текущим названиям.

## Контент, модерация и движение

- [ ] Короткий/длинный русский текст, emoji, длинные слова и URL не ломают плашку.
- [ ] HTML из сообщения отображается текстом.
- [ ] Нативные Twitch emotes находятся на правильных позициях.
- [ ] Игнорируемые пользователи и скрытие команд работают.
- [ ] Удаление сообщения/сообщений пользователя убирает нужные карточки.
- [ ] Вход, покачивание и выход корректны; частота/размах 0 выключают покачивание.
- [ ] 11 фоновых рисунков включаются по отдельности, плотность учитывает короткие плашки.
- [ ] Случайные рисунки и повороты не перекрывают друг друга; смена идёт через затухание.
- [ ] Изменение шрифта/размеров пересчитывает фон без пересечения рисунков.

## Длительная работа

- [ ] Сцена проверена с реальным потоком сообщений и целевыми размерами OBS.
- [ ] Количество DOM-узлов остаётся ограниченным лимитом сообщений.
- [ ] Память и CPU не показывают устойчивого роста после удаления старых сообщений.
- [ ] После удаления виджета/размонтирования не остаётся активных таймеров.
