# Manual QA Checklist

## Подготовка

- [ ] Выполнено `npm ci && npm run check`.
- [ ] SHA-256 ZIP совпадает.
- [ ] Четыре вкладки установлены в новый Custom Widget.
- [ ] Разрешения StreamElements Overlay и OBS Browser Source совпадают.
- [ ] Проверка выполняется на тестовом Twitch-канале без публичной трансляции.

## Роли

- [ ] Обычный viewer получает viewer theme.
- [ ] Subscriber получает subscriber theme.
- [ ] VIP получает VIP theme.
- [ ] Moderator получает moderator theme.
- [ ] Broadcaster получает broadcaster theme.
- [ ] Пользователь с несколькими ролями получает оформление по приоритету.

## Контент

- [ ] Короткое сообщение.
- [ ] Длинное многострочное сообщение.
- [ ] Очень длинное слово и URL не выходят за bubble.
- [ ] Unicode и emoji отображаются корректно.
- [ ] RTL-текст имеет корректное направление.
- [ ] Нативные Twitch emotes отображаются в правильных местах.
- [ ] Twitch badges можно включить и отключить.
- [ ] Строка `<img src=x onerror=alert(1)>` показана как текст.
- [ ] Command message скрывается при включённом `Hide command messages`.
- [ ] Ignored user не появляется.

## Размещение

- [ ] Одно сообщение находится внутри сцены.
- [ ] Несколько быстрых сообщений обычно не пересекаются.
- [ ] Edge padding соблюдается.
- [ ] Safe zones не занимаются в обычном сценарии.
- [ ] При заполненной сцене UI остаётся стабильным и без зависания.
- [ ] Изменение разрешения Browser Source перестраивает сообщения.

## Lifecycle и модерация

- [ ] Enter animation завершается.
- [ ] Idle motion не требует постоянного JavaScript loop.
- [ ] Exit animation завершается удалением DOM node.
- [ ] Удаление конкретного сообщения сразу убирает его.
- [ ] Очистка сообщений пользователя убирает только его сообщения.
- [ ] Max messages удаляет самое старое сообщение.
- [ ] Перезапуск Browser Source очищает старое состояние без ошибок.
- [ ] После отключения/удаления widget сообщения не продолжают появляться.

## Настройки и ассеты

- [ ] General settings применяются после сохранения.
- [ ] Animation dropdowns работают для всех вариантов.
- [ ] Character image заменяется для каждой роли.
- [ ] Decoration image заменяется для каждой роли.
- [ ] Отключение role theme использует viewer fallback.
- [ ] Некорректный safe zones JSON не ломает widget.

## Длительная работа

- [ ] Overlay открыт не менее двух часов с потоком сообщений.
- [ ] Количество DOM nodes остаётся ограниченным.
- [ ] Память стабилизируется после удаления старых сообщений.
- [ ] В OBS нет заметного роста CPU из-за idle animation.
