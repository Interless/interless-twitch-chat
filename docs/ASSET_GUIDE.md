# Персонажи, шрифты и графика

## Свои динозавры

В стандартном релизе нет готовых персонажей. Чат работает без них, пока не загружен набор.

1. В превью выбери папку или файлы WebM/MP4/GIF/WebP/PNG/APNG. Поддерживается до 50 файлов, 16 МиБ на файл и 64 МиБ суммарно.
2. Начальная команда создаётся из имени файла: `trex.webm` → `!trex`. Кириллица в имени транслитерируется для внутреннего ID. Одинаковые ID отклоняют импорт.
3. При необходимости измени поле «Команда» в карточке. Название можно написать латиницей или кириллицей; файл и назначения зрителей сохраняются.
4. Сохрани проект JSON, скопируй четыре вкладки в StreamElements и выбери **те же исходники** в «Динозаврики — медиатека».

Исходные байты сохраняются в локальном проекте; в JS эфира они не включаются. В эфире используется медиа из StreamElements. Допустимость формата/размера при загрузке в медиатеку определяется самим сервисом.

Новая папка заменяет предыдущий набор. Файлы не отслеживаются в фоне. После их изменения повтори импорт, перенос метаданных и выбор файла в медиатеке. «Очистить загруженных» удаляет локальный набор, сохраняя оформление.

## Размер и качество

Персонажи вписываются в общий квадрат с сохранением пропорций. При импорте сохраняется полный кадр; прозрачные поля внутри исходника уменьшают видимую фигуру. Для сходного визуального размера заранее обрежь лишние поля и используй сопоставимую композицию кадров.

Размер динозавра регулируется отдельно; общий масштаб дополнительно меняет всю карточку вместе с ним. CSS зеркалит персонажей, расположенных справа. Видео отображается как muted/autoplay/loop/playsInline; фактическое воспроизведение и прозрачность проверяй в целевом OBS.

GIF → WebM может изменить вес и совместимость, но не вернуть отсутствующие детали. Виджет не делает автоматическое улучшение, обрезку или сжатие медиа. Для WebM/MP4 важен не только контейнер, но и кодек, поддерживаемый браузером OBS. Используй исходник достаточного разрешения для планируемого масштаба; огромный canvas для маленькой фигуры не добавляет ей деталей.

## Замена непосредственно в StreamElements

В настройках Custom Widget открой «Динозаврики — медиатека». Поле «Файл» выбирает существующий файл или открывает загрузку. Поле «Команда» меняет название без изменения внутреннего ID. После выбора/переименования нажми Save.

Если новый файл отличается кадром или размерами, сначала обнови его и в превью, затем скопируй актуальные метаданные. Добавление совершенно нового персонажа в 0.21.0 требует импорта в превью и повторного копирования кода; дополнительных пустых слотов ещё нет.

## Графика оформления

Костяная рамка, нижние выступы и края плашки находятся в `src/assets/*.svg`. Не объединяй имя, текст, персонажа и рамку в общий растр: отдельные элементы позволяют переносить текст, менять ширину и цвет.

`src/components/RoleBadge.tsx` содержит корону, молоток, меч, алмаз и таракана. Значок выбирается по нормализованной роли. Дополнительные нативные значки подписки и другие картинки остаются, если их URL пришёл в событии. Общий `showBadges` скрывает все значки.

`src/config/decorationIcons.json` содержит 11 фоновых рисунков. Их цвет, видимость, комбинация и размещение настраиваются в превью. [Описание регуляторов](CONFIGURATION.md).

## Шрифты

Десять семейств с кириллицей поставляются локально. Полный набор WOFF2 встроен в превью; экспорт оставляет одну выбранную гарнитуру. В Windows их устанавливать не нужно. Текст лицензий находится отдельно в `FONT-LICENSE.txt` архива и не копируется в StreamElements.

Исходные TTF, WOFF2 и OFL находятся в `src/assets/fonts/`. `src/config/fontCatalog.json` хранит источники и SHA-256. Для воспроизводимого пересоздания WOFF2:

```bash
python3 -m pip install fonttools brotli
python3 scripts/prepare-fonts.py
```

Скрипт проверяет хеш исходника, карту символов и метрики после конвертации. Он не меняет глифы и не удаляет символы.

## Лицензии

Код и собственная SVG-графика распространяются по MIT, шрифты — по приложенным OFL. Пользовательские персонажи не включены в репозиторий и стандартный релиз. Их лицензии не заменяются лицензией кода виджета.
