# Настроить в превью → перенести в StreamElements

## 1. Превью и сохранение проекта

1. Распакуй архив и открой `preview.html` в браузере. Если уже есть сохранённый JSON проекта из предыдущей версии, нажми **Открыть проект** и выбери его: оформление и локальные анимации восстановятся.
2. Настрой цвета, шрифт, прозрачность, размеры, расположение, анимации плашек и фоновые значки. В разделе **Динозаврики — команды и выбор** выбери свою папку или отдельные файлы. Стандартных персонажей нет. Имя файла задаёт начальную команду: `trex.webm` → `!trex`. Чтобы изменить её, отредактируй поле **Команда** в карточке и нажми **Изменить команду**. Файл переименовывать не нужно. Новый набор заменяет предыдущий.
3. Проверь персонажей кнопкой **Назначить случайных динозавриков** и своим тестовым сообщением.
4. Нажми **Сохранить проект**. JSON содержит оформление и исходные файлы для дальнейшего редактирования в превью. Это локальная копия проекта; она не вставляется в StreamElements.

В превью работают WebM/MP4/GIF/WebP/PNG/APNG: до 50 файлов, 16 МБ на файл и 64 МБ всего. Допустимость файла при загрузке в медиатеку определяет StreamElements; если сервис отклоняет формат, используй поддерживаемый файл, например WebM для видео или GIF/PNG для изображения.

## 2. Копирование кода

1. Открой [StreamElements](https://streamelements.com/dashboard/overlays) → **Streaming Tools → Overlays**. Открой существующий Overlay или создай новый.
2. Добавь **+ → Static / Custom → Custom Widget**, либо выбери существующий виджет нашего чата. Нажми **Open Editor**.
3. В превью нажми каждую из четырёх кнопок. В StreamElements полностью замени содержимое соответствующей вкладки через Ctrl+A → Ctrl+V:

| Вкладка StreamElements | Кнопка в превью    |
| ---------------------- | ------------------ |
| HTML                   | Скопировать HTML   |
| CSS                    | Скопировать CSS    |
| JS                     | Скопировать JS     |
| FIELDS                 | Скопировать FIELDS |

Если браузер запрещает буфер обмена, в превью появится выделенный код — нажми Ctrl+C вручную. **FIELDS теперь содержит кнопки выбора файлов для твоих динозавров**, а не `{}`. Оформление настраивается в превью. Дополнительно FIELDS создаёт ползунок **Общий масштаб чата (%)**, доступный прямо в StreamElements.

4. Примени изменения и закрой редактор кода. Выдели Custom Widget и открой его настройки слева.
5. Перейди к загрузке медиа по инструкции ниже. Без выбранных файлов чат работает без динозавров.

## 3. Загрузка динозавров в медиатеку

1. В настройках Custom Widget найди группу **Динозаврики — медиатека**. Она появляется после вставки FIELDS из превью с загруженными персонажами.
2. Для каждого персонажа будут два поля: **Команда: имя персонажа** и **Файл: имя персонажа**. В поле команды можно вписать своё название, например `!барни` или `!trike`. У видео будет выбор видео, у GIF/PNG — выбор картинки.
3. Нажми кнопку выбора файла рядом с нужной командой. В открывшейся медиатеке нажми **Upload** / загрузку файла, выбери на компьютере **тот же исходный файл, который использовался в превью**, дождись окончания загрузки.
4. Выдели загруженный файл и подтверди выбор кнопкой **Submit** / **Select**. Для следующего персонажа повтори эти действия. Если файл уже есть в твоей медиатеке, просто выбери его повторно — загружать заново не нужно. Подписи кнопок могут отличаться в разных версиях интерфейса.
5. Нажми **Save** в Overlay Editor.

Ссылки на файлы сохраняются в настройках StreamElements автоматически. Не нужно копировать URL, заводить собственный сервер или пережимать видео. Копируемый JS содержит метаданные персонажей, а сами анимации загружаются отдельно из медиатеки. Размер JS больше не растёт на размер исходных анимаций.

**При переходе со старой версии полностью замени старый JS:** он содержит встроенные анимации. Одной замены FIELDS недостаточно. Если в Overlay есть другие старые копии нашего виджета с большими встроенными файлами, их также нужно обновить или удалить ненужные копии: StreamElements сохраняет весь Overlay целиком.

## Масштаб чата

В превью открой **Размеры и расположение чата → Общий масштаб чата**. Ползунок 25–200% масштабирует рамки, динозавров, текст, значки и промежутки вместе. 100% — исходный размер. Отступы от краёв сцены и привязка блока сохраняются. Отдельный **Размер динозавриков** позволяет дополнительно менять их пропорцию относительно плашек.

В StreamElements в настройках Custom Widget открой группу **Масштаб чата → Общий масштаб чата (%)**. Двигай ползунок и нажми **Save** — повторно копировать код не нужно. При первой установке используется масштаб из превью. Если в том же виджете уже сохранён масштаб, проверь его после обновления кода: значение из DATA имеет приоритет для этого ползунка.

Масштаб из превью сохраняется через **Сохранить проект**. Изменение только в StreamElements не возвращается автоматически в локальный проект. Остальные настройки оформления по-прежнему берутся из скопированного кода.

## Команды и их переименование

Команду можно менять в превью или прямо в настройках Custom Widget в StreamElements, рядом с выбором файла. В StreamElements после изменения нажми **Save**; код повторно копировать не нужно. Файл медиа, размеры и назначения зрителей остаются привязаны к тому же персонажу. Старая команда перестаёт выбирать его. Новая команда работает для следующих сообщений автора.

Можно писать с `!` или без него; регистр не важен. Допускаются латиница/кириллица, цифры, `_` и `-`, первая — буква, длина — 1–32 знака без `!`. Команды должны быть уникальны. `!dino`, `!ichat` и `!interless_chat` зарезервированы для справки. В превью ошибка показывается под полем и изменение не применяется. При недопустимой или повторяющейся команде в StreamElements используется исходная команда из превью: исправь название и сохрани Overlay.

Команды из превью сохраняются через **Сохранить проект**. Изменения, сделанные только в StreamElements, не возвращаются автоматически в локальный JSON проекта. Чтобы превью и последующий экспорт использовали те же названия, измени их также в превью. Текст ответа бота со списком команд обнови отдельно — виджет не редактирует Custom commands бота.

## 4. OBS и проверка

1. Задай области Custom Widget достаточную ширину и высоту для всего чата.
2. Скопируй URL Overlay. В OBS: **Источники → + → Браузер**, вставь URL и укажи разрешение Overlay. Если источник уже есть, используй его; при необходимости обнови источник браузера.
3. Напиши в Twitch свою команду (например `!trex`), затем обычное сообщение. Персонаж появится у следующего сообщения автора.

Тестовые сообщения, фон страницы превью, закрепление тестовых сообщений и случайные назначения авторов не переносятся в эфир. Время жизни сообщений берётся из настройки чата, а не из режима закреплённого предпросмотра.

## 5. Последующие изменения

Открой сохранённый проект в новом `preview.html`, настрой нужные параметры и снова скопируй HTML/CSS/JS/FIELDS в **тот же Custom Widget**. **Не очищай вкладку DATA**: там хранятся выбранные файлы StreamElements. При сохранении тех же команд поля имеют те же имена. После замены кода проверь выбор файлов в группе медиатеки; если поле пустое, выбери уже загруженный файл.

Если меняешь саму анимацию, выбери новый файл и в превью, и в StreamElements. Превью определяет размеры и команду исходного файла; используй одинаковые файлы для обоих этапов.

В StreamElements переносится один выбранный шрифт WOFF2. Остальные шрифты остаются в превью. Цвета, размеры и анимации фиксируются по текущим значениям. Отдельно вставлять пресет не нужно, старый пресет не перекрывает новое оформление. Для OBS остаётся прежний URL.

JSON проекта сохраняет локальные анимации, а выбор файлов в медиатеке хранится отдельно в StreamElements. Превью не входит в аккаунт StreamElements и не загружает туда файлы автоматически.

Команды выбора динозавров работают в самом виджете. Чтобы список команд писал бот StreamElements, отдельно настрой Custom commands; список своих персонажей показан под галереей в превью.

Официальные инструкции: [поля выбора медиа](https://docs.streamelements.com/overlays/widget-structure), [редактор Custom Widget](https://docs.streamelements.com/overlays/first-custom-widget), [подключение Overlay в OBS](https://support.streamelements.com/hc/en-us/articles/10474479981074-Adding-Overlays-to-OBS-Studio).
