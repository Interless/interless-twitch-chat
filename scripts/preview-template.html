Interless 0.13.0 — локальный просмотр

Скопировать в StreamElements Настрой чат и нажми название нужной вкладки — её код скопируется. В StreamElements открой ту же вкладку, выдели старый код (Ctrl+A) и вставь новый (Ctrl+V). Передаются всё оформление и только выбранный шрифт. Динозаврики загружаются отдельно в медиатеку StreamElements.
Скопируй все четыре вкладки. Затем в настройках Custom Widget открой «Динозаврики — медиатека» и загрузи файлы для каждой команды. Анимации в JS не встраиваются.
«Сохранить проект» сохраняет JSON для повторного редактирования здесь — вместе с настройками и анимациями.
Быстрое подключение
  1. Настрой оформление и загрузи своих динозавриков.
  2. В StreamElements открой Overlay → Static / Custom → Custom Widget → Open Editor.
  3. По очереди нажми «Скопировать HTML», «Скопировать CSS», «Скопировать JS», «Скопировать FIELDS» и вставь каждый код в одноимённую вкладку.
  4. Закрой Open Editor. В настройках Custom Widget открой «Динозаврики — медиатека». Для каждой команды нажми выбор видео или картинки → Upload → выбери тот же файл, что в превью → Submit. Сохрани Overlay кнопкой Save.
  5. Скопируй URL Overlay в OBS → Источники → Браузер. Размер источника — как у Overlay.
Оформление настраивается здесь, файлы для эфира хранятся в StreamElements. После изменения оформления скопируй четыре вкладки заново. Вкладку DATA не очищай — там сохраняется выбор медиа.
Дополнительно: JSON пресета Дополнительно: компактный JSON только с настройками (без загруженных анимаций).
Передаются настройки оформления, движения, значков и расположения. Тестовые сообщения и личный выбор зрителей в пресет не входят.

Динозаврики — команды и выбор
trex.webm → !trex. Выбранная папка заменяет предыдущий набор. Кириллица транслитерируется. Команду можно изменить в карточке ниже: введи название и нажми «Изменить команду». Допускаются латиница, кириллица, цифры, _ и -, до 32 знаков; первый — буква. В StreamElements команда также редактируется рядом с выбором файла. После переименования старая команда не сохраняется как алиас. Папка читается при выборе. Для сохранения загруженных анимаций используй «Сохранить проект». После изменения файлов выбери папку повторно. До 50 файлов, 16 МБ на файл, 64 МБ всего. Это файлы для локального просмотра. После копирования кода загрузи те же файлы в разделе «Динозаврики — медиатека» в StreamElements: сервер и ручное копирование ссылок не нужны. Нажми команду — персонаж сразу заменится у показанных сообщений ника из поля выше. Если таких сообщений ещё нет, появится тестовое. В Twitch команда меняет только следующие сообщения автора. Меняет персонажей у всех авторов в превью. У одного автора — один персонаж; повторные нажатия позволяют просмотреть каталог.
!dino, !ichat и !Interless_chat — список. В Twitch отвечает реальный бот StreamElements после настройки Custom commands бота; здесь показан текст списка команд для ответа.
Фоновые значки — палеонтология
Больше плотность — больше значков, пока хватает места. Короткая плашка вмещает меньше. Все переключатели можно сочетать. Частота смены: 0 — статичный рисунок, 100 — новый каждые 3 секунды. Плотность 0 или выключенные значки убирают декор. Случайные позиции и углы, без пересечений. Цвет — в палитре, пункт «Фоновые значки».
Палитра RGB — цвета элементов
Выбери элемент и задай любой цвет. Изменения сразу видны в чате. Меняются цвета всех ролей для выбранного элемента. Анимации динозавриков и изображения Twitch остаются в исходных цветах.
Enter — отправить · Shift+Enter — новая строка. Загрузи своих динозавриков в разделе выше.
